## 📌 Sobre este repositorio

Este repositorio contiene el **sitio web de presentación** del Trabajo Fin de Ciclo **iMirly**, desarrollado como proyecto final del ciclo de **Desarrollo de Aplicaciones Multiplataforma** en New Digital Talent, Granada.

La web está construida con **HTML, CSS y JavaScript puro**, sin frameworks, y recoge toda la información del proyecto: la idea, el mercado, el diseño UX, la aplicación, la tecnología y el equipo.

## 🗂️ Estructura de la web

La presentación se divide en **6 páginas** que cubren cada dimensión del proyecto:

| Página | Descripción |
|:---|:---|
| **🏠 Inicio** | La idea, propuesta de valor, misión y objetivos |
| **📈 Mercado y estrategia** | Análisis de mercado, competencia, DAFO y plan de ventas |
| **🎨 Diseño & UX** | Concepto visual, paleta, experiencia de usuario y prototipado |
| **📱 Aplicación** | Funcionalidades, flujo de uso y enfoque frontend |
| **⚙️ Tecnología** | Arquitectura del sistema, stack técnico y modelo de datos |
| **👥 Equipo** | Miembros, roles y forma de trabajo |

## 🛠️ Tecnologías

  <img src="https://img.shields.io/badge/HTML5-3f51b5?style=for-the-badge&logo=html5&logoColor=white"/>
  <img src="https://img.shields.io/badge/CSS3-6c5ce7?style=for-the-badge&logo=css3&logoColor=white"/>

- **Sin frameworks ni dependencias externas** — solo tecnologías base de la web
- **Diseño responsive** adaptado a móvil, tablet y escritorio
- **Animaciones CSS** y efectos de scroll con Intersection Observer
- **Footer y header compartidos** inyectados dinámicamente vía JavaScript
- **Menú flotante de navegación** con scroll spy activo

## 🧩 Arquitectura del proyecto

```bash
iMirlyPresentacion/
│
├── index.html                  # Inicio — La idea, misión y objetivos
├── mercado-y-estrategia.html   # Mercado, competencia, DAFO y plan de ventas
├── diseno-ux.html              # Diseño visual, UX y prototipado
├── aplicacion.html             # Funcionalidades y flujo de la app
├── tecnologia.html             # Stack técnico y arquitectura del sistema
├── equipo.html                 # El equipo y forma de trabajo
│
├── styles.css                  # Estilos globales y componentes
├── main.js                     # Lógica principal: scroll, animaciones, nav
└── footer.js                   # Footer inyectado automáticamente
```
